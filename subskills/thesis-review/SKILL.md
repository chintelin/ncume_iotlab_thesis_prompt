# 全文與格式檢查

## 呼叫方式與交接

由 [main_skill.md](../../main_skill.md) 選擇本模組，或依學生明確指定直接使用。先讀取 [共同原則](../../shared_rules.md)，再讀本次需要的內容。

- **輸入：** 待檢查稿件、圖表、參考文獻、適用要求與已有確認紀錄。中途盤點時加上目前階段、預計下一項工作及所需前置成果。
- **輸出：** 檢查範圍、完整度判斷與證據位置、規範不符與內容不足清單，以及學生可執行的修改或補充提示；問題交由修訂管理加入 checklist，盤點結果回傳任務規劃。
- **回傳主流程：** 完成內容與檔案位置、使用的資料版本、學生確認狀態、待補項目與建議下一步。

需要學術圖時，將圖的目的、資料與尺寸交給 [學術圖製作](../../ieee-academic-figures/SKILL.md)，再接回本模組。一般比較表或工作表可在本模組完成。產生待修工作或實際修改時，將紀錄交給 [修訂管理](../revision-management/SKILL.md)。

## 既有內容完整度盤點

學生已有部分內容、準備接續研究或寫作時，先判斷本次所需的既有成果。按研究目的與下一項工作的需求檢查，保留可沿用的內容；未完成的後續階段仍列為未開始。以內容、來源與相依關係評估完整度，避免僅依章數、字數或學生自述判定完成。

先建立成果索引，標明章節、圖表、程式或數據的位置及版本，再檢視本次相關範圍。較長稿件分次檢查，對外回報本次已讀取與尚未檢視的範圍。AI 先整理已有資訊；需要學生核對或補資料時，每次安排一項 60–90 分鐘的工作。

依內容類型選用下列判準，細節沿用相應子 skill：

| 成果類型 | 判斷能否支持下一步的重點 |
|---|---|
| 目的、RQ／H | 問題與範疇清楚；假說具比較對象、條件、指標及判定依據，或明確指出尚待查證部分 |
| Related Work | 比較可回溯來源；文獻與研究目的的差距、本文範疇及 RQ／H 彼此連接 |
| 方法與實驗設計 | 圖表與實作一致；方法理由、輸入輸出、baseline、控制條件及測量方式足以支援預定工作 |
| 結果與 Discussion | 結果可追溯實際數據與設定；圖文一致；已提出的 findings 有證據、解釋、替代解釋與範圍 |
| 寫作與呈現 | 段落論證完整、引用可查、術語一致，並符合共同原則；正式圖稿另核對可編輯性、尺寸、字級與灰階 |

尚未確認的要素會影響下一步時，依下表標為需補強或待查證。研究設計階段檢查預定驗證方式；已有結果時才檢查實際判定。只有圖表草稿時，先判斷其內容能否支持下一步；正式製圖要求保留到相應任務核對。

| 盤點結論 | 判定與記錄方式 |
|---|---|
| 可沿用 | 已核對的內容與證據符合本次判準。註明適用範圍、版本及確認狀態 |
| 需補強 | 已確認有缺項、矛盾或規範不符。列出位置、依據、補強動作與完成判準 |
| 待查證 | 存在相關主張或材料，但來源、設定或確認紀錄不足以判定。列出所需證據與取得方式 |
| 尚未開始 | 依學生回覆或工作紀錄確認尚未執行，列為後續任務 |
| 未檢視 | 本次未讀取或無法取得相應內容，保留判斷，記錄待檢範圍 |

每項結果另記「是否影響下一步、受影響任務、理由」。可沿用表示該範圍足以支持指定工作；不代表整章或全篇已完成終稿檢查。學生確認圖表與 AI 的完整度判斷分別記錄，使用圖表撰寫內文時仍核對確認狀態。致謝只核對原文是否保留。

將盤點寫入學生的 `thesis_task_board.md`，詳細問題沿用 R 編號登錄 checklist。回傳任務規劃時列出可沿用成果、關鍵缺項與建議先處理的一項工作；較大缺口由任務規劃拆成小任務。補強完成後只重查受影響的內容與依賴，保存判定變更的理由及證據。

## 檢查全文與格式

依序檢查研究邏輯、數據一致性、表達與版面。將問題整理成「位置、問題、建議修訂、所需資料」。以下項目供終稿檢查使用；中途盤點依目前階段與已完成範圍選用，未開始的後續內容依任務規劃處理。

致謝原文排除於潤飾、錯字修正、人稱替換與格式改寫範圍。只核對原文有無保留。

- 每項 RQ 有對應的回答。
- 每項 H 有方法、實驗與判定結果。
- 每項貢獻有正文證據。
- 摘要、結果與結論中的數值一致。
- 圖表、公式、術語及縮寫一致。
- 中英文摘要、正文、圖表說明及生成範例避免第一人稱，並優先使用主動語態。
- 論述段落具有明確主題、充分展開與上下文承接；檢查單句段落，依語意合併或補充有依據的說明。
- 同段句子圍繞同一重點，段間依主題與論證進程分隔；合併零碎段落，拆開混合多個主題的長段。
- Related Work 明確連結文獻差距、研究目的與本文範疇。
- Discussion 的 findings 包含證據、解釋、設計意涵與適用範圍。
- 引用可對應到完整的參考文獻資料。
- 方法與實驗資訊足以支持重現。
- 封面、摘要、目錄、頁碼與附錄符合適用範本。
- 依適用規定處理研究倫理、資料授權與 AI 使用揭露。
- 簡短自傳包含出生年、最高兩項學歷、工作與重大成就，並附學生確認的正式作者照片；缺項記錄明確。
- 分章 Markdown 的總目錄、上下章連結、論述承接及引用編號一致，全部分檔屬於同一本論文。

> **請提供：** 本次使用的論文範本與指導教授要求。
>
> **可修改範例：** 範本檔名：[填入]；版本日期：[填入]；特別要求：[填入]；預計輸出：Markdown（預設），另需格式：[Word／LaTeX／PDF／無]。

輸出文件時，使用環境中可用的文件工具。檢查匯出後的版面，特別注意跨頁表格、圖說、公式與目錄。

段落檢查先閱讀前後文，再建議調整位置及理由。句數可協助找出候選問題，仍需依論述完整性判讀。圖說、表格、公式與清單不套用正文段落的句數判斷，致謝保持原文。

## 提示學生修改與補充

依共同原則的提示格式回報每個實際問題，保留 R 編號供後續追蹤。先指出內容的位置與問題，再說明具體動作，讓學生可直接回覆。

### 範例一：寫作規範不符

> **位置與原文：** [檔名、章節與段落]：「本方法較有效。」
>
> **問題：** 單句段落未展開論證，且「有效」缺少判定依據。
>
> **依據與理由：** 本 skill 要求完整學術段落與具體技術敘述。讀者需要知道比較條件、指標與證據。
>
> **請學生處理：** 提供比較方法、測試條件、實際結果與圖表位置，並確認本句應與哪一段整合。
>
> **可修改範例：** 在 [條件] 下，本方法的 [指標] 為 [數值]，比較方法為 [數值]。圖 [編號] 呈現各次實驗的 [結果或變異]。這些結果在 [適用範圍] 內支持 [具體判讀]。
>
> **完成判準：** 以實際資料替換欄位，核對圖文一致，並將內容整合成上下文連貫的完整段落。

### 範例二：內容不足

> **位置與缺項：** [Related Work 檔名與段落] 已摘要文獻方法，尚缺與研究目的的比較及本文範疇。
>
> **依據與理由：** 本 skill 要求明確連結文獻差距與本文處理範圍，讓讀者理解研究必要性。
>
> **請學生補充：** 文獻的測試條件與證據位置、與本研究目的的具體差距，以及本文將處理的條件。
>
> **可修改範例：** 文獻 [編號] 在 [條件] 下評估 [指標]，證據位於 [章節或頁碼]。本研究希望回答 [RQ]，因此仍需釐清 [缺少的證據]。本文將以 [方法與條件] 處理此問題，研究範圍為 [範疇]。
>
> **完成判準：** 比較內容可回溯文獻，研究差距連到 RQ／H，本文範疇與實際方法及實驗一致。

學生提供資料後，重新檢查對應問題及連動段落。部分補充完成時，保留剩餘缺項；完成的修改寫入摘要，尚未完成的項目留在 checklist。
