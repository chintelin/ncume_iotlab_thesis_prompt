# 簡短自傳與正式作者照片

## 呼叫方式與交接

由 [main_skill.md](../../main_skill.md) 呼叫，並沿用 [共同原則](../../shared_rules.md)。此模組處理作者資料，致謝維持原文。

- **輸入：** 學生提供的簡短自傳或資料表、本人照片、適用的論文或投稿範本。
- **輸出：** 簡短自傳 `.md`、照片檔案與規格紀錄、待補事項及學生確認狀態。
- **回傳主流程：** 文字與照片版本、確認狀態、檔案位置。交由 [Markdown 組稿](../markdown-assembly/SKILL.md) 納入同一本論文。

## 先請學生提供資料

請學生提供一段簡短自傳與正式作者照片。可先填寫下表，再整理為段落。

| 必要資料 | 填寫內容 | 可修改範例 |
|---|---|---|
| 姓名 | 與論文作者姓名一致 | [中文姓名]／[英文姓名] |
| 出生年 | 年份並註明紀年 | 西元 [年份] 年 |
| 最高學歷 | 學校、系所、學位、年份與狀態 | 國立中央大學 [系所] 碩士班，[年份] 入學，目前在學 |
| 次高學歷 | 學校、系所、學位、年份與狀態 | [大學] [學系] 學士，[年份] 畢業 |
| 工作經歷 | 單位、職稱、期間與工作內容 | [公司] 軟體工程師，[起訖年份]，負責 [工作] |
| 重大成就 | 成果名稱、年份、角色與具體貢獻 | [年份] 完成 [專案]，負責 [模組]；或取得 [獎項／專利／發表] |
| 正式照片 | 本人原始照片檔案或位置 | [檔案路徑]，直式頭肩照，原始像素 [寬 × 高] |

區分已取得學位與在學狀態。工作可包含正式職務、兼職或實習，清楚標示類型。沒有工作或重大成就時，請學生明確填寫「無」或提供實際專題成果。學歷不足兩項時記錄實際情況，待學生說明。

> **請提供：** 簡短自傳或上表資料，以及本人正式作者照片。
>
> **用途：** 完成論文作者簡介，供教師核對學經歷與作者資料。
>
> **可修改範例：** 作者出生於西元 [年份] 年，於 [年份] 取得 [學校] [領域] 學士學位，目前就讀國立中央大學 [系所] 碩士班。作者於 [期間] 擔任 [單位與職務]，負責 [工作內容]。主要成果包括 [年份、成果及個人貢獻]。

範例供學生替換，使用已提供的事實形成簡短段落。以第三人稱與主動語態整理；只有學生提供並確認時，才列出 IEEE 會員資格、獎項或其他身分。出生年與最高兩項學歷是教師要求，與期刊個別的簡介規定分開記錄。

## 正式 IEEE 作者照片

請學生提供可用於正式出版的本人照片，採清楚的頭肩構圖、自然表情與簡潔背景，保留原始高解析度檔案。服裝與構圖保持專業；這是本 skill 的準備建議。

以指定 IEEE 期刊或會議的作者照片範本確認尺寸與格式。未指定範本時，初稿採寬高比 4:5，版面預設為寬 25.4 mm、高 31.75 mm；正式投稿前再核對。作者照片採獨立規格，不套用學術圖的 8／14 cm 寬度。

IEEE Author Center 接受高解析度 JPEG 作為作者照片，並列出其他可用格式。彩色或灰階點陣圖依最終尺寸核對有效解析度；本 skill 採 400 dpi 作為工作目標。以上述初稿尺寸計算，裁切後至少 400 × 500 px 可達此目標，並優先保留更大的原始影像。

檢查照片的清晰度、比例、頭肩位置及灰階辨識度。需要裁切時另存版本，保持人物比例及本人特徵。學生尚未提供照片時，保留待補紀錄，請學生提供實際檔案。

> **可修改照片紀錄：** 原檔：[路徑]；裁切版：[路徑]；像素：[寬 × 高]；預計尺寸：[寬 × 高 mm]；有效 DPI：[數值]；適用範本：[名稱與版本]；學生確認：[待確認]。

## Markdown 交付與確認

將自傳存為 `author_biography.md`，或依論文既有命名規則存入作者資料章節。照片放在同一本論文的資源目錄，使用相對路徑連結。以下僅為輸出範例，依實際路徑調整：

```markdown
# 作者簡介

![作者正式照片](../assets/author_photo.jpg)

[依學生資料整理的自傳段落]
```

Markdown 預覽不代表正式印刷尺寸。將照片的版面尺寸保存在製作紀錄，匯出論文時依範本設定。

- 核對姓名、出生年、兩項學歷的年份與狀態。
- 核對工作、成就及個人貢獻。
- 確認照片為學生提供的版本，影像品質與格式適用。
- 請學生確認整段自傳與照片，再標示「學生已確認」。

待補資料與實際修改交由 [修訂管理](../revision-management/SKILL.md) 記錄。
