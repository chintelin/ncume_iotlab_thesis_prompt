# Markdown 組稿與章節串接

## 呼叫方式與交接

由 [main_skill.md](../../main_skill.md) 呼叫，並沿用 [共同原則](../../shared_rules.md)。此模組整理學生論文輸出，字數門檻不適用於 skill 指令檔本身。

- **輸入：** 已有論文或各章內容、章節順序、圖表與照片、引用、學生確認狀態及版本。
- **輸出：** 單檔論文，或總目錄與互相串接的章節 `.md`，另附變更紀錄。
- **回傳主流程：** 入口檔、檔案順序、字數口徑與各檔字數、連結檢查結果、待補資料。

## 預設格式與拆分條件

論文預設使用 UTF-8 Markdown。學生指定其他格式時，保留 Markdown 工作稿，再依要求產生對應輸出。照片、數據與可編輯圖稿保留原生格式並連結。

單檔正文超過 5,000 字時，可按章節拆分。未超過門檻可保留單檔；學生已有分章稿時沿用。依實際內容分檔，保留完整段落、圖說、表格與公式。

字數採一致的工作口徑：計算可見正文的非空白字元，包含中英文、數字與標點；排除中繼資料、Markdown 語法標記、連結目標與程式碼區塊。記錄使用的工具及口徑。學生另有字數算法時沿用其指定方式。5,000 字整不算超過門檻。

單章仍超過 5,000 字且適合分拆時，可依節或小節拆分。各分檔仍維持原章編號與順序。

## 檔案結構

單檔模式以 `thesis.md` 為正文。分章模式以 `thesis.md` 為總目錄，記錄同一論文的題名、作者、版本、章節順序與檔案位置。實際檔名沿用學生的既有規則。

以下是結構範例，章序依適用範本調整；僅建立已有內容或本次需要的檔案：

```text
thesis.md
chapters/
  01_introduction.md
  02_related_work.md
  03_methodology.md
  04_experimental_design.md
  05_results.md
  06_discussion.md
  07_conclusion.md
  author_biography.md
references.md
assets/
  author_photo.jpg
  fig03_D1.pptx
  fig03_D1.png
```

單檔轉分章時，將正文完整移入分檔，再將原入口改為目錄。保留修訂前版本供核對，避免出現兩份同時維護的正文。

## 將各檔視為同一本論文

1. 各章使用同一題名、版本與研究設定，維持連續章節編號。
2. 在章節開頭與結尾加入「上一章／總目錄／下一章」相對連結。第一章與末章只列實際存在的相鄰章節。
3. 章末交代本章結論及下一章的用途；下一章開頭承接前章已建立的結果或前提。接續文字依實際內容撰寫。
4. 術語、縮寫、符號、RQ、H、finding、圖表與公式編號跨檔一致，沿用適用範本的編號方式。
5. IEEE 引用以整本論文的閱讀順序管理，同一來源沿用同一編號。參考文獻集中管理，不因分檔重新從 `[1]` 開始。
6. 跨章提及內容時，連到目標檔案或穩定標題錨點。章節改名或移動後更新所有相關連結。
7. 各章連結同一份圖表與照片資源。修改圖稿時，同步更新相關內文、摘要與結論。

導覽範例（請依實際檔案調整）：

```markdown
[上一章：緒論](01_introduction.md) · [總目錄](../thesis.md) · [下一章：研究方法](03_methodology.md)
```

以下為章節過渡句範例。將它們整合到既有的完整段落，避免單獨形成一句話的正文段落：

> 第 2 章結尾：上述比較指出，突發負載下的尾端延遲仍缺少評估。第 3 章據此說明負載感知排程的設計。
>
> 第 3 章開頭：依據第 2 章界定的範圍，本章說明排程器如何取得負載資訊並分派任務。

## 致謝保留規則

致謝保留學生原文，排除於潤飾、格式修正、第一人稱替換及承接文字新增範圍。原本是獨立檔時，保留原檔不動，由總目錄與相鄰章節連到它。

致謝原本包含在待拆分稿件時，可將其內容原樣保存為獨立檔，逐字核對原文，並保留原始稿件。致謝檔內不新增導覽；用外部目錄與相鄰章節維持全篇連接。尚無致謝時，將缺項記在 checklist。

## 交付前檢查

- 確認拆分前後內容完整，致謝原文一致。
- 依總目錄走訪全部章節，檢查上一章、下一章與返回目錄的連結。
- 檢查相鄰章節的論述承接，移除分檔造成的重複介紹。
- 保持完整論述段落，依上下文合併單句碎段；在主題或論證階段改變時分段，不為換檔或湊字數切開段落。
- 核對章節、圖表、公式與引用編號，確認跨檔連結及資源路徑有效。
- 記錄拆分前後檔案對應與各檔字數，交由 [修訂管理](../revision-management/SKILL.md) 寫入修改摘要。

最後交付入口檔與全部相依檔案，讓教師可按順序閱讀同一本論文。
